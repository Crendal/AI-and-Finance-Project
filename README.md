# 포트폴리오 트래커 (Portfolio Tracker)

주식/ETF 포트폴리오를 추적하고 관리하는 웹 대시보드입니다.

## 주요 기능

- **거래 기록**: 매수/매도 거래를 날짜, 가격, 수량, 수수료와 함께 기록
- **보유 종목 관리**: 평균 매수가, 현재가, 수익률 자동 계산
- **NAV 그래프**: 포트폴리오 전체 가치 추이를 시각적으로 확인
- **자산 배분 차트**: 종목별 비중을 도넛 차트로 표시
- **다중 통화 지원**: USD/KRW 통화 지원 및 환율 설정
- **데이터 내보내기/가져오기**: JSON 파일로 백업 및 복원

## 사용 방법

1. `index.html`을 브라우저에서 열기
2. "거래 추가" 메뉴에서 매수/매도 기록 입력
3. "대시보드"에서 전체 현황 및 NAV 그래프 확인
4. "보유 종목"에서 현재가 업데이트
5. "거래 내역"에서 과거 거래 조회/수정/삭제

## 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript
- Chart.js (차트 라이브러리)
- localStorage (데이터 저장)
